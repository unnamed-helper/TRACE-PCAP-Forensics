Details

Open capture

PCAP and PCAPNG files are streamed from disk in chunks. File size is limited only by your machine's memory for the decoded packets.

Drop files here or click to browse.pcap · .pcapng · .cap — select several to merge them into one timeline

Suricata engine

Runs your locally installed Suricata against the loaded capture file(s) through the local service (backend.py). Alerts shown are real engine output — never simulated.

Copy .rules files into the rules folder next to backend.py; they are used instead of Suricata's own rule list.

Built-in rule engine — runs rules without Suricata

Experimental subset of the rule language, evaluated in this browser against the loaded capture. Supports header/flow/flags/dsize, content (+nocase/depth/offset/distance/within), pcre, and http.uri / http.method / http.user_agent / http.host / http.header / dns.query / tls.sni. Rules needing anything else (flowbits, byte_test, app-layer-event, file.*…) are listed as skipped, never silently ignored. Suricata's stock *-events.rules detect engine parser events and need Suricata itself.

The selected capture file is sent only to the service on this machine. Suricata reads it offline (-r); traffic is never replayed onto a network interface.

Help & limits

TRACE decodes captures in the browser and can hand them to a local Suricata engine for signature detection.

Filter syntax (Packets tab)

ip:10.0.0.5 src:… dst:… (CIDR ok: ip:10.0.0.0/8, wildcard: ip:192.168.*) port:443 sport: dport: (ranges: port:8000-8100) proto:tcp|udp|dns|http|tls|icmp|arp flag:syn flag:syn,ack flag:synonly len>500 len<=64 dns:example.com http:/login sni:corp host:name text:"cmd.exe" "plain words" has:finding has:payload flow:12 file:cap1 -proto:dns (prefix a term with − or ! to exclude it)

Shortcuts

/ focus filter · j / k next / previous packet · Esc close panel · b bookmark packet

What to trust

Suricata detections are produced by the real engine and your local rules.
Heuristic findings (scan, beaconing, DNS anomalies, cleartext credentials, …) are threshold-based leads computed in the browser. Validate them against packet context.

Limits: TLS is not decrypted; TCP stream view is best-effort reassembly (no out-of-order buffering beyond sequence ordering); IP fragments are not reassembled; link types supported: Ethernet, raw IP, Linux cooked (SLL/SLL2), BSD loopback. Large captures are bounded by the decode limit you choose and by browser memory.
